# Security Policy

## Supported Versions

Only the latest released version receives security fixes. Upgrade to the latest release to receive security updates.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

The current version is recorded in `herdr-plugin.toml` and published on the [releases page](https://github.com/maro114510/herdr-toggle-popup/releases).

## Reporting a Vulnerability

Report security issues privately. Never use a public issue, pull request, or discussion for a suspected vulnerability. The report stays private between you and the maintainer until it is resolved.

Private reporting channels:

| Channel | Action |
| --- | --- |
| GitHub advisory form | Open the [private security advisory form](https://github.com/maro114510/herdr-toggle-popup/security/advisories/new) |
| Security tab | Open the repository Security tab and select Report a vulnerability |

Include the following details in the report:

| Field | Detail |
| --- | --- |
| Version | Affected herdr-toggle-popup version and install method |
| Environment | Herdr version, tmux version, operating system, and architecture |
| Impact | The issue and its security impact |
| Reproduction | Steps to reproduce, ideally minimal |
| Diagnostics | Output of the doctor command when it is relevant |
| Fix | Any suggested fix or mitigation |

Remove tokens, credentials, and other secrets from logs before attaching them.

## What to Expect

| Topic | Policy |
| --- | --- |
| Review | Reports are reviewed on a best-effort basis |
| Timeline | No fixed response or resolution time is promised |
| Resolution | A fix is released and the advisory is published |
| Credit | You are credited unless you prefer to stay anonymous |

## Scope

This policy covers the herdr-toggle-popup plugin and its released binaries. Report issues in Herdr or tmux to those projects.
